EDGE GeoIntelligence Airborne Gamma Survey
Spectrogram × Flight Log

Gamma / Flight-Log Join Portal

Upload a FORMAT 3 gamma spectrogram and its matching Airdata flight log. We time-synchronise every spectrum to precise drone position and kinematics, emit a joined CSV (all channels + SI-unit flight parameters) and a dual calibration report (factory Cs-check + best-fit survey). Results land in a dedicated Google Drive folder named after your job.

1. Project details

Identifies your run and names the output folder & files.

Used verbatim in output filenames (letters, numbers, _ and - only).

2. Input files

One spectrogram text file and one Airdata flight-log CSV.

GammaSpectacular / ImpulseQt export. First line must read FORMAT: 3.

Must contain time(millisecond), datetime(utc), latitude, longitude.

3. Join & calibration settings

Sensible defaults are pre-filled — adjust only if you know the instrument.

Max gap when matching a spectrum to the nearest flight-log fix. 1 s suits typical 1–10 Hz Airdata logs (≈1–5 m position error); widen only for sparse logs.

Advanced — factory (Cs-check) calibration coefficients

E = a0 + a1·ch + a2·ch² + a3·ch³  (from the ImpulseQt calibration screen).
